## Whole-project influences

- **Lich** — the session-and-scripts split, the `;` command language and the detachable client. See [why-python.md](why-python.md).
- **dr-scripts** — the reference for a script library; see [scripting.md](scripting.md).
- **Pylanthia** — [robbintt/pylanthia](https://github.com/robbintt/pylanthia), the other Python DragonRealms client.
- **Elanthipedia** — where every mechanic above was researched first.
